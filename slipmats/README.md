# Slipmat concepts

Four 12 inch turntable slipmat concepts built only from the brand rules in `handoff/README.md`: ink `#141310` and paper `#F7F5F0`, Overpass Mono only, the master cat artwork unaltered, 1px ink rules, no gradients, tints, textures or shadows. Each is a 1000 x 1000 SVG with a real 7.5mm spindle hole cut out (a PNG preview sits beside it). `contact-sheet.png` shows all four.

| File | Idea |
|---|---|
| `01-watcher-paper` | Paper mat, the cat watching from the lower left, wordmark top right, label rings round the spindle. |
| `02-flip` | The site's signature move on a mat: paper above, ink below, and the cat flips colour exactly at the boundary. Side B of the pair. |
| `03-reserve-ink` | Ink mat with the cat's face filling it in paper, eyes staring, the spindle hole as the nose. Uses the reserve (eyes crop) silhouette. |
| `04-tracklist` | Type only. The DNA list, the catalog genres and the sides wrapped as grooves round an ink centre label. |

Text in the SVGs uses an embedded copy of Overpass Mono. Convert text to outlines before sending to a printer.
